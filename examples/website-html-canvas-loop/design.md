# HTML → Beam canvas

Use the actual desktop editor primitives: EditorTitlebar, EditorWorkspace,
TimelineToolbar, ZoomPanel, TimelineTrackHeaders, TimelineZoomTrack, the shared
TimelineCanvasLane/surface/painter and the original timeline CSS. Keep their
light/dark theme tokens, typography, row heights, trim handles and 2D/Manual
badges. Generate timeline thumbnails from the actual authored HTML output.

A compact source pane demonstrates editing scene.html; it represents the source
workspace beside Beam, not a new code-editor feature inside the product. The
canvas contains the same actual HTML artwork throughout: edit its title, save,
change the CSS accent and rotate its motif. The two native camera zooms focus the
code and then the canvas, returning to the complete editor/timeline.

Keep the film silent, 12 seconds, 60 fps, seekable and loopable. Capture at 2×
for crisp native 1.5× camera moves. The artwork uses warm paper, charcoal and
Beam orange; the application keeps its real colors without a decorative
background or custom approximation of its timeline.
