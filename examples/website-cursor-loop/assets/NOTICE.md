# Artwork and dependencies

Source: MPL-2.0, following the Beam repository license.

- Complete macOS pack: unchanged Beam assets from `public/macOsSvgCursors/`,
  frozen through media-use. Existing applicable third-party rights remain;
  see `docs/agents/templates/assets/NOTICE.md`.
- Complete Material Bibata Noir artwork: unchanged PNGs from Beam's bundled
  `public/cursorPacks/assets/`, preserving intrinsic size and hotspots. Catalogue
  aliases share 54 distinct artworks. Original applicable rights remain;
  no independent license is claimed.
- UI controls are imported from Beam's desktop primitives; icons use Lucide.
- The thin screenshot-selection shape uses Beam’s native SVG tint helper for theme contrast; original files are preserved.
- Tide is Beam's own gradient preset, painted by its actual runtime renderer.
- Hanken Grotesk: SIL Open Font License, alongside the font.
- Vue, GSAP and Lucide retain their own licenses.

This fictional editing illustration uses explicitly authored input events.
Cursor motion, motion blur, role resolution, size geometry, click spring and
ripples are evaluated by Beam's real engine. It is not a captured recording.
The loop is intentionally silent. External FFmpeg only creates the website
derivatives; no FFmpeg binary or library is bundled by this example.
