Short, silent English command demonstration for the private site's
“Made for agents to work with” section. One stable terminal, three real CLI
commands, original Beam colors, generous type, no busy background.
7 seconds, 1280 × 800, 60 fps, matching light and dark versions.

Discover tools, inspect an open document, then apply a revision-checked edit.
Use the installed `beam-cli` launcher. `@project.json` contains a project ID;
`@edit.json` contains the current revision, operation ID and engine commands.
Captions explain behavior; this is an illustrated command reference,
not a recording or fabricated tool output.

User explicitly requests the finished video. Render and integrate autonomously.
Sol handles all work, as required by the repository/user instructions.
Animation uses the deterministic terminal primitive from HyperFrames;
the deliverable renders through the real Beam CLI, as in the preceding video.

Acceptance: real syntax, readable in the feature card, gentle closed loop,
seek-safe animation, themed posters, shared pause/reduced-motion controls.
