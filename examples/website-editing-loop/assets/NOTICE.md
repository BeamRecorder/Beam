# Local reference assets

- `beautiful-captures.webp` is a downscaled Beam CLI export of the user's existing
  **Beam — Beautiful Captures** Screenshot project, ID
  `f6591292-6029-47ee-b9d5-e0db743de757`. It is used in the preview and thumbnail
  strip, with permission from the request. Beam artwork and the original project
  remain the reference; third-party platform marks are not relicensed.
- `HankenGrotesk.ttf` is copied from Beam's public font directory. Its unmodified
  SIL Open Font License is included in `HankenGrotesk-OFL.txt`.
- The arrow and horizontal-resize cursors are unchanged copies of Beam's
  `public/macOsSvgCursors/default.svg` and `resizewesteast.svg`, frozen by
  media-use in `.media/images/`. Geometry/hotspots use the actual macOS pack
  descriptors. These third-party representations retain their applicable rights;
  no new license, Apple affiliation or CC0 dedication is claimed. See the existing
  cursor provenance in `docs/agents/templates/assets/NOTICE.md`.
- Vue, GSAP and Lucide retain their own upstream licenses. Beam UI primitives,
  timeline paint code and theme CSS are imported directly from this repository.
- The fixed background uses Beam's Ember preset and gradient renderer. The saved
  recipe is rendered once; it has no animated clock or ambient glow.
- The HyperFrames `oversized-cursor` catalog item was consulted for the actor
  pattern. The video uses Beam's macOS cursor assets and native components.

This is a fictional editing demonstration, not a recording of interactive editor
operations. The waveform is illustrative; the website loop is intentionally silent.
