# Record — final two demonstrations

Two silent 8-second loops, 1280 × 800 at 30 fps, in light and dark.
Use the actual Beam teleprompter view, RecorderBar and Project Picker controls.
Use the Beautiful Captures Figma pointer and Sonoma Horizon catalog wallpaper.
Keep motion in 2D: a gentle teleprompter push-in, a native 1.8× Projects zoom, eased cursor paths and a short reset fade.

- Teleprompter: a prepared script, Play, continuous reading at 42 px/s, Text size, enlarge from 26 to 34 px, close, Text color, choose readable coral in the native triangle picker, close, continue reading.
- Projects: frozen real local catalog, zoom toward website-demo and its action menu with Beam’s native manual 2D camera, select the project, Explore, pull back as the file browser opens, reveal the real original recording in an illustrative HTML file browser.

Render with Beam CLI; compress to VP9 WebM and extract matching WebP posters.
Integrate into website-private /features/recording, preserving the shared player.
