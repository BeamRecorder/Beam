# Cursor asset provenance

The four SVGs in `cursors/` are unchanged copies of Beam's existing
`public/macOsSvgCursors/` assets: `default.svg`, `handpointing.svg`,
`textcursor.svg` and `handgrabbing.svg`. Hotspots match the descriptors in
`apps/desktop/src/components/editor/properties/cursor/cursor-packs.ts`.

These are third-party macOS cursor representations. This example does not claim
ownership, an Apple affiliation, a CC0 dedication, or a new license for them.
No independent upstream license was found beside the source assets. Reuse is
subject to any applicable rights; supply your own licensed cursor assets when
you need independently established redistribution terms.

The generic template code has no Zaro logos, interface crops or soundtrack.
GSAP remains subject to its own package license; consult that license when adapting
the example. The code's repository license does not relicense third-party assets.
