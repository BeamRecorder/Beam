# README imagery

These optimized images are reused unchanged from Beam's website, with the maintainer's supplied artwork and existing Beam demonstrations. They are stored in the repository so the README does not depend on temporary attachment links.

- `beautiful-captures.jpg`: the maintainer-supplied **Beautiful Captures** Beam artwork, also used as the website's social preview.
- `studio-dark.webp` and `studio-light.webp`: the website's Studio demonstration, showing Beam's real editor components, timeline, recorded screen, webcam, captions and zooms. The editable demonstration is documented in [`examples/website-studio-loop`](../../../examples/website-studio-loop/README.md).
- `screenshot-layers.webp`: the website's Screenshot composition demonstration using the same Beautiful Captures artwork and Beam's editable layers and grouping controls.
